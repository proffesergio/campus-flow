# Phase 4 — Full Bilingual (EN/বাংলা) Implementation Plan

> REQUIRED SUB-SKILL: subagent-driven-development. Each task = one fresh subagent.

**Goal:** Make EN⇄বাংলা actually translate the app by wiring `useTranslations`/`getTranslations` into every in-scope screen and filling `messages/en.json` + `messages/bn.json` (Bangla AI-generated).

**Architecture:** next-intl is already wired (`i18n/request.ts` reads `NEXT_LOCALE` cookie; `LanguageToggle` flips it + `router.refresh()`). Work = replace hardcoded strings with `t('ns.key')` and keep `en.json`/`bn.json` key sets in sync. Namespaces extend the existing ones.

**Spec:** `docs/superpowers/specs/2026-06-09-i18n-phase-4-design.md`. **Branch:** `feature/i18n-phase-4`.

**Conventions for EVERY task:**
- Client screens: `import { useTranslations } from 'next-intl'; const t = useTranslations('<ns>');` → `t('key')`.
- Add the key to BOTH `messages/en.json` (English) and `messages/bn.json` (natural Bangla) under the same path.
- Reuse `common` for shared verbs (Save/Cancel/Add/Edit/Delete/Search/Loading/Back/Next/Export/Import…).
- Do NOT translate dynamic data (names, emails, user input) or backend/validation messages.
- After each task: `cd frontend && npm test && npx next build` must pass; commit.

---

## Task 1: i18n foundation + nav + parity test
**Files:** `frontend/messages/en.json`, `frontend/messages/bn.json`, `frontend/lib/i18n-parity.test.ts`, `frontend/app/(dashboard)/layout.tsx`
- Ensure `common`, `nav`, `auth`, `status` namespaces are complete in en.json and **fully translated to Bangla** in bn.json (buttons, nav labels, sidebar group headings, profile menu items, search placeholder, logout, role labels).
- Add `frontend/lib/i18n-parity.test.ts` (vitest): recursively collect key paths from en.json and bn.json; assert the two sets are equal (fails if any key missing on either side). This guards every later task.
- Wire `app/(dashboard)/layout.tsx`: nav group labels + item labels (currently in the `navGroups` array — move display to `t('nav.*')`), profile dropdown (My Profile/Settings/Logout), search placeholder, role labels, "Notifications"/"Mark all read"/"View all".
- Run test + build. Commit: `feat(i18n): foundation namespaces, bn translations, parity test, translated nav`.
